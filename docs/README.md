# Einfuehrung-GitHub
GitHub kennen- und nutzen- lernen mittels kleiner Projekte

# Projekte

## Hello-World-Projekt
Das erste Einführungsprojekt mit simpler Ausgabe von "Hello World!".
Geschrieben ist das Programm in **Python**. Abgesehen von einem *Python-Debugger*
werden keine weiteren Tools benötigt.

## Startprojekt C#
Das zweite Programm ist geschrieben in **C#**.
Inhalt des Programms ist eine Schleife, welche bei 1 startet.
Während das Programm läuft, wird um 1 hochgezählt, bis 10 erreicht ist.
In jedem Durchlauf wird einmal die aktuelle Zahl ausgegeben.
**Wichtig:**
Für das Programm wird das C#-Developement-Kit benötigt und das Programm
kann nicht als einzelne Datei sondern nur als Teil eines Projektes funktionieren.

## Startprojekt Java
Das dritte Programm geschrieben in **Java**, ist ein Frage-Antwort Spiel.
Der Nutzer wird nach und nach gefragt, wie er/ sie/ es heißt und wie alt er/ sie/ es ist.
Auf jede Eingabe des Nutzer folgt eine Antwort der ein Kommentar vom Programm.
Nach der letzten Eingabe beendet das Programm sich in jedem Fall selbst.
**Wichtig:**
Um das Programm schreiben und ausführen zu können wird das "Extension Pack for Java" benötigt.
Wie bereits bei C# kann auch das Java Programm nicht als einzelne Datei, sondern nur innerhalb
eines Projektes existieren.

# Ziele
Das Gesamtprojekt Einfuehrung-GitHub verfolgte den Plan, ein Grundverständnis für GitHub zu entwicklen.
Unteranderem sollten folgende Ziele erfüllt werden:
- [ ] Entwicklungsumgebung Installieren und testen
- [ ] Mit Git arbeiten: Commit, Verlauf, README, Projektstruktur
- [ ] Probleme Dokumentieren und anschließend beheben
